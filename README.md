# GENESIS — Become A God 🌌

یک ربات تلگرامی که در آن هر بازیکن یک خداست: زمین می‌سازد، حیات را تا انسان تکامل می‌دهد،
و بعد تمدنی که خودش خودکار رشد می‌کند (نسل، جنگ، اختراع، دین) را با قدرت‌های الهی هدایت می‌کند.
چندنفره است: می‌توانی به دنیای دوستت سر بزنی و برکت/نفرین/بلا بفرستی.

این نسخه‌ی **هسته‌ای (core)** بازی است — کاملاً کار می‌کند، اما پایه‌ای برای گسترش بیشتر است
(نقشه‌ی گرافیکی، جنگ‌های پیشرفته، اقتصاد کامل و... را می‌شود بعداً ماژول به ماژول اضافه کرد).

## فایل‌ها
- `bot.py` — کل منطق بازی (تک‌فایلی، تمیز و قابل توسعه)
- `requirements.txt` — کتابخانه‌های لازم
- `Procfile` — به Railway می‌گوید چطور اجرا شود
- `.gitignore`

## ۱) گرفتن توکن ربات
۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
۲. `/newbot` را بزن و اسم/یوزرنیم دلخواه بده.
۳. توکنی که می‌دهد را نگه دار (چیزی شبیه `123456:ABC-DEF...`).

## ۲) گذاشتن روی گیت‌هاب
```bash
git init
git add .
git commit -m "GENESIS core"
git branch -M main
git remote add origin https://github.com/USERNAME/genesis-bot.git
git push -u origin main
```

> توکن ربات را **هرگز** داخل کد یا گیت‌هاب نگذار. آن را فقط به‌صورت متغیر محیطی (Environment Variable) در Railway ست کن.

## ۳) دیپلوی روی Railway
۱. وارد [railway.app](https://railway.app) شو و با گیت‌هاب لاگین کن.
۲. **New Project → Deploy from GitHub repo** و ریپوی `genesis-bot` را انتخاب کن.
۳. در تب **Variables** این متغیر را اضافه کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
   - (اختیاری) `TICK_SECONDS` = هر چند ثانیه دنیا یک سال پیش برود (پیش‌فرض ۱۸۰)
۴. Railway به‌طور خودکار از `requirements.txt` نصب می‌کند و طبق `Procfile` ربات را اجرا می‌کند.
۵. مطمئن شو سرویس روی **Worker** ست شده (نه Web) چون این ربات polling است و پورت باز نمی‌کند.

## ۴) بازی با رفیقت
هر دو نفر در تلگرام به ربات `/start` بزنید — هرکدام دنیای خودش را می‌گیرد.
از منوی «👥 دنیاهای دیگر» می‌توانید به دنیای هم سر بزنید و برکت/نفرین/بلا بفرستید.

## دستورات
- `/start` — شروع بازی / منوی اصلی
- `/status` — وضعیت دنیای فعلی
- `/history` — تاریخچه‌ی جهان

## نکته درباره‌ی دیتابیس
با SQLite کار می‌کند (`genesis.db`، خودکار ساخته می‌شود). روی Railway اگر سرویس ری‌استارت شود
و دیسک پایدار (volume) وصل نکرده باشی، دیتابیس ریست می‌شود. برای پایدار ماندن داده‌ها:
یک **Volume** در Railway به سرویس وصل کن و `DB_PATH` را روی مسیر آن ولوم بگذار،
یا بعداً به PostgreSQL مهاجرت کن (ساختار کد برای این کار آماده و ساده است).

## توسعه‌ی بعدی (پیشنهادی، قدم‌به‌قدم)
- جنگ بین تمدن‌ها و سیستم امپراتوری
- نقشه‌ی تصویری (تولید عکس با Pillow)
- اقتصاد و بازار کامل
- ماجراجویی فضایی و کهکشانی
- AI Gods خودکار وقتی بازیکن انسانی نیست

هر کدام از این‌ها را که خواستی، به‌صورت یک ماژول جدا اضافه می‌کنیم تا `bot.py` مدیریت‌پذیر بماند.
